WRECKAGE
for WRECKEM. Oct 29 2026. From Austin.

WINDOWS / FL STUDIO (64-bit Windows 10 or 11)
1. Close FL Studio and WRECKAGE, then run WRECKAGE-Setup.exe and approve
   the administrator prompt. Setup installs the VST3 and standalone app.
   If Microsoft WebView2 is missing, setup installs it (internet required).
2. FL Studio: Options > Manage plugins > Find more plugins.
   WRECKAGE shows up under Generators. Star it, then load it from Channel rack +.
3. WRECKAGE also runs from the Start menu without FL Studio.

Manual install (from the portable CI artifact): copy the entire WRECKAGE.vst3
folder into C:\Program Files\Common Files\VST3\. Keep the bundle intact.
Install Microsoft's WebView2 Evergreen Runtime if the interface is blank:
https://developer.microsoft.com/microsoft-edge/webview2/

Updates: close FL Studio and WRECKAGE, then run the new installer.
Remove via Windows Settings > Apps > WRECKAGE > Uninstall.
Your saved presets stay in Documents\WRECKAGE\Presets.
Install guide and downloads: https://austnnnnnn.github.io/wreckage/

MAC
WRECKAGE.vst3 goes in ~/Library/Audio/Plug-Ins/VST3/, WRECKAGE.component in ~/Library/Audio/Plug-Ins/Components/.
It isn't signed, so run this once in Terminal:
  xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/WRECKAGE.vst3 ~/Library/Audio/Plug-Ins/Components/WRECKAGE.component

YOUR PRESETS
Saved as plain .wreck files in Documents\WRECKAGE\Presets. Back them up, send them to people,
drop other people's in there. CRATES opens the browser: SAVE AS to name, tag and sign a patch,
click the tags to filter, star the ones you keep coming back to. Arrow keys step through the list.

PLAYING
Computer keys A to L play notes, Z and X change octave. Double-click any knob to reset it,
shift-drag for fine moves. The mod wheel pushes RUST.

There's more in here. Try the wall.
